# Automated Library / Bookstore Management System

A Java-based console application for managing library and bookstore operations.

## Features
- Book inventory management
- Search books by title, author, series, or genre
- Automatic section, rack, and shelf allocation
- Customer purchasing and bill generation
- Condition-based and bulk discounts
- Purchase history tracking
- Stock management and sales reports
- Librarian authentication

## Technologies Used
- Java
- Java Collections Framework
- File Handling
- CSV Data Storage

## How to Run

1. Install the Java Development Kit (JDK).
2. Download `LibrarySystem.java`.
3. Open a terminal in the folder containing the file.
4. Compile and run:

```bash
javac LibrarySystem.java
java LibrarySystem
```

The application automatically creates `books.csv` and `purchases.csv` when needed to store inventory and purchase records.
